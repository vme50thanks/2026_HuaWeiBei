# 四问成果总索引

本目录为原工作区 outputs 的完整副本，保留原目录结构，以维持各问之间的相对引用。原始题目、附件和原工作区成果未修改。

## 目录

- preflight：公共预处理数据、数据核验报告、航段和时间规则。
- q1：第一问单点往返运输与货箱组批的代码、结果、图表（如有）、报告及原成果包。
- q2：第二问异构无人机运输调度的代码、基准和替代方案、图表与独立检查记录。
- q3：第三问运输与中继联合调度的代码、轨迹、通信核验、图表、报告及成果包。
- q4：第四问冻结调度分区的代码、分区方案、资源配置、图表、报告及成果包。
- paper：已经保存的论文结构资料。聊天中输出但未单独保存的 LaTeX 正文不包含在此目录中。
- D题求解前数据包.zip：原预处理数据包。
- 文件清单_SHA256.csv：复制文件的相对路径、大小及 SHA-256；已逐文件与工作区源文件核对。

## 阅读与复算

先阅读各问目录内的模型报告、独立检查报告及 README，再查看 baseline 或 K2_baseline、K3_baseline 中的基准结果。替代方案及敏感性结果按原目录名保留，不混入基准提交表。

代码、依赖说明与复算命令按原文件完整保留。本次为归档复制，没有改写代码或重新求解；部分脚本和复算说明可能引用原工作区或原附件的绝对路径，迁移到其他电脑时需按各问说明调整。文件哈希核验不等于在新目录重新执行通过。

第三问通信结论仍仅为在所述时空分辨率下未发现中断；第四问继承该限制。最优性范围、工作假设和库存缺口以各问报告为准。
